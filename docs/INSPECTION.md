# 검증 모드

v0.3.1부터 실행 중 **Ctrl + Shift + F8**로 엽니다. 개인 인증이나 비밀 키는 사용하지 않습니다. 이 조합을 아는 다른 사용자도 켤 수 있습니다. 일반 메뉴에는 검증 버튼을 표시하지 않습니다.

| 조작 | 동작 |
|---|---|
| Ctrl + Shift + F8 | 검증 창 열기/닫기 |
| 구간 → 입구로 이동 | 1~40 중 선택한 구간에서 새 검증 시작 |
| X / Y → 좌표로 이동 | 지정한 월드 좌표로 이동 |
| Ctrl + 왼쪽 클릭 | 현재 화면에서 클릭한 월드 지점으로 이동 |
| F9 / 자유 이동 | 충돌과 중력을 적용하지 않는 비행 전환 |
| WASD / 방향키 | 비행 중 좌우·상하 이동 |
| Shift | 비행 속도 4배 |
| 무적 | 비행을 끈 상태에서도 함정 사망 방지 |
| 비행 중 장치 정지 | 비행 중 함정·발판·사슬의 동작 정지/재개 |
| 현재 위치를 출발점으로 | 검증 중 사망·R 재시도의 복귀 위치 설정 |
| R | 현재 검증 출발점에서 재시도 |

구간 이동은 장치·아이템·타이머를 초기화하고 해당 입구를 검증 출발점으로 설정합니다. 40번은 39번 가짜 문을 지나 도착하는 시점의 공유 타이머도 복원합니다. 사망하거나 R로 재시도해도 이 연결을 유지합니다. 좌표/마우스 이동은 기본적으로 현재 장치 상태를 유지합니다. 비행 중에는 기본으로 장치가 정지하며, 옵션을 끄면 캐릭터 위치에 반응하며 다시 동작합니다. 비행 자체로는 시간·체크포인트·비밀 별·클리어를 갱신하지 않습니다.

검증 창을 열면 캐릭터와 시간이 멈춥니다. 닫기/Esc로 직전 플레이 상태로 돌아갑니다. 비행을 해제하면 일반 충돌과 중력을 다시 적용하므로 지형 안이나 낭떠러지에서 해제할 때는 입구 이동을 사용할 수 있습니다.

## 기록

최초 활성화 때 현재 정상 기록을 한 번 저장하고 이후에는 `user://inspection_records.json`에 저장합니다. 기존 `records.json`은 검증 중 다시 쓰지 않습니다. 창을 닫아도 해당 실행 세션은 계속 검증 기록을 사용합니다. **게임을 완전히 종료하고 재실행하면 일반 모드**로 시작합니다. 테스트는 `test_inspection_records.json`을 사용합니다.

## 사진의 점프대/약한 발판 구간

24번입니다. v0.4.0부터 점프대 오른쪽 지면은 주변 바닥과 같은 외형입니다. 해당 구간만 검증하려면 검증 창의 구간을 24로 선택합니다.

1. 오른쪽 납작한 점프대를 밟습니다. Space 없이 자동으로 발사됩니다.
2. 최고점에 가까워질 때 D를 떼어, 점프대 오른쪽 바닥의 중앙에 내려앉습니다.
3. 착지 충격으로 발판이 부서지면 아래 받침을 따라 오른쪽 턱까지 이동합니다.
4. 턱에 바짝 붙은 위치에서 D와 Space를 길게 눌러 올라갑니다. 너무 일찍 점프하면 위 문 아랫면에 머리가 걸릴 수 있습니다.

이 안내는 사용자가 요청한 구간 공략이며 게임 화면에 공략 팻말을 추가하지 않습니다. `tests/playthrough.gd --room=24`를 실제 이동/점프 입력으로 통과시켜 확인했습니다.

## 35번 하부 통로

0.4.0은 하부 두 지점을 각각 한 번 밟아 잠금을 해제하는 구간입니다. `X≈23868`을 밟고 `X≈23988`로 이동한 뒤 바로 D+Space로 오른쪽 턱을 넘으면 통과합니다. 두 지점을 동시에 누르거나 계속 서 있을 필요는 없습니다. 첫 구역이 좁아 평범하게 걸어 내려오면 이를 공중으로 지나칠 수 있었고, 작동 피드백도 없어 해법을 알기 어려웠습니다.

0.4.1은 일반 보행 착지를 포함하도록 감지 구역을 조정했습니다. 밟은 쪽의 문 걸쇠가 움직이고 작동음이 나며, 두 걸쇠가 모두 풀리면 실제 문이 올라갑니다. 순서는 무관하고, 잠긴 문에 접촉하는 것 자체는 사망 원인이 아닙니다. 바닥 공격은 장치가 약 0.3초간 올라오는 모습을 거쳐 작동합니다. 게임 안에는 좌표·센서 표시·공략 문구를 추가하지 않습니다.
