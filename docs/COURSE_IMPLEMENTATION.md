# 연속 코스 구현 — v0.3.0

초기 40개 카드를 토대로 지형과 런타임 구조를 교체했다. 다섯 장을 로드하거나 장마다 종료하지 않는다. 단일 월드 25,600px에 40개 만남을 연결했고 실제 체크포인트는 x=10,272와 20,512 두 곳이다. 방 번호는 개발/검증용이며 게임에 표시하지 않는다. 처음 640px는 점프를 잡고 다음 구간은 보행과 긴 점프를 잡아, 초반부터 같은 조작만 반복해서 진행할 수 없게 했다.

## 구조

- `course.gd`: 구간별 바닥 틈·고정 지형·동적 표면·기믹 배치. 640px 단위는 편집 좌표이며 카메라 잠금이나 방 전환이 아니다.
- `world.gd`: 모든 충돌 지형을 한 번 구성하고 현재 카메라 범위만 그린다. 이전 해상도 맞춤·최대화·F11 복귀를 유지한다.
- `encounter.gd`: 40개 센서/판단과 대기→발동→활성→소진 상태. 물리 120Hz 시계로 위험 도형, 스위치, 이동 표면을 갱신한다. 사망 횟수나 난수로 규칙을 바꾸지 않는다.
- `surface.gd`: 실제 콜라이더를 가진 붕괴/이동/승강/벨트. 캐릭터에 표면 변위와 접촉 중 벨트 속도를 적용하고 이탈 속도를 추가 상속하지 않는다.
- `device.gd`: 실제 접촉으로 얻는 공중 점프 1회 충전, 다리/미끼 아이템, 점프대, 매달리고 오르내리는 사슬.
- `player.gd`: 기본 이동/가변 점프/코요테/버퍼, 충전 공중 점프, 벽 슬라이드·W 오르기·벽 점프, 사슬 오르내리기와 점프 이탈. 점프대는 -760px/s로 발사하며 버튼 해제로 잘리지 않는다.

사망·재시작은 모든 센서, 타이머, 발자국 예약, 표면 위치·충돌, 아이템, 미끼, 압력판, 가짜 연출, 사슬 소유와 임시 점프 충전을 함께 초기화한다. 이미 활성화한 체크포인트는 사망 시 유지한다. 일시정지 중 입력과 시계·표면·사슬은 멈춘다. 가짜 피격과 가짜 문은 실제 사망/클리어/입력 잠금을 호출하지 않는다.

## 기록 호환

같은 사용자 폴더와 기존 저장 형식을 사용한다. 누적 시작/사망/클리어와 소리 설정은 보존한다. 맵이 달라진 이전 최고 시간·무사망·비밀 기록은 `legacy.meadow-v1`로 보관하고 새 코스의 해당 기록을 별도로 시작한다. 플레이 도중 위치는 현재 체크포인트에서만 복귀하며 프로그램 재실행 후 위치를 복원하는 기능은 기존처럼 제공하지 않는다.

## 검증

- `playthrough.gd`: 시작 x=100부터 실제 좌우/점프/W 입력만 사용한 40개 연속 통과. `--room=N`은 별도의 개발용 단일 구간 재현으로 전체 통과와 구별한다.
- `wrong_routes.gd`: 40개 각각에 대해 오답 입력 한 가지가 실제 충돌·낙사로 끝나는지 검사. 40번 단독 시험만은 39번 문 통과 후 경과 시간을 fixture로 설정한다.
- `course_tests.gd`: 전체 40개 상태의 일시정지, 초기화, 동일 입력 재현과 사슬·가짜 피격·가짜 출구의 실제 게임 상태 분리.
- `run_tests.gd`: 이동/가변 점프/충전/벽/점프대/기록·오디오·저장 오류·이전 기록 이관.
- 해상도와 업데이트 HTTP 검사는 계속 수행한다. 전체 40개의 모든 입력 타이밍에 8프레임 여유가 있다는 수치나 모든 숙련 우회 차단을 확정하지 않는다. 현재 증거는 지정한 정답 연속 입력과 구간별 오답, 상태 계약 검사다.

최종 로컬 결과: 시스템/이동/기록 57개, 구간 계약 131개, 오답 40개, 해상도 103개, HTTP 업데이트 84개로 총 415개 검사를 통과했다. 전체 공략은 16,608물리 틱, 138.40초, 사망 0회, 체크포인트 2개 및 비밀 별을 기록했다. 동일 입력을 30fps(4물리 틱/렌더 프레임)로 재생해 매 물리 틱의 위치를 0.1px 이내로 비교했고, 이동 발판·사슬·승강기에서 각 24물리 틱씩 멈췄다 재개해도 같은 결과였다. 이는 작성한 공략 입력의 재현 증거이며 사용자가 처음 보고 같은 시간에 통과할 수 있다는 뜻은 아니다.

렌더 캡처: `godot --path . --fixed-fps 120 --audio-driver Dummy --script tests/capture.gd -- --test`. 시각 검토를 위해 장면 초기 위치를 설정하며, 전체 통과의 증거에는 이 캡처 위치 설정을 사용하지 않는다.
