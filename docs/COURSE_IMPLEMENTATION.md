# 연속 코스 구현 — v0.4.0

단일 월드 **27,968px**에서 길이 560~896px의 40개 만남을 끊김 없이 진행한다. `WIDTHS`, `OFFSETS`, `origin()`, `number_at()`이 실제 경계를 정의하며 카메라 잠금·방 전환은 없다. 감지 위치도 구간마다 다르다. 체크포인트는 **x=10,992와 22,304 두 곳**이며 추가하지 않았다. 구간 번호와 아래 해법은 개발 문서에만 있다.

## 이번 변경과 판단

- 초반의 낮은 지형은 짧은 점프, 뒤의 높은 장애물은 긴 점프로 넘는다. 첫 함정은 공중 진입에 반응하며, 평지에서 이유 없이 점프해야만 드러나는 구조를 바꿨다.
- 7번 충전은 실제 보상이며 8번의 다리 열쇠도 실제 보상이다. 27·28번 모두 첫 배를 이용할 수 있지만 27번은 9물리 틱 이내 재도약해야 한다. 인접한 장치가 매번 반대 답을 요구하는 순서를 줄였다.
- 20번은 실제 바닥 접촉, 21·22번은 교환 구간 진입, 33번은 타일 접근 시 공격 시계를 시작한다. 입구 센서를 켠 뒤 후퇴해 2초를 기다리는 기존 공략으로 위험을 소진할 수 없다. 21·22번의 교환에는 뒤 문이 닫히며, 긴/짧은 체공의 차이가 남는다.
- 4번은 머리 접촉으로 통로를 조기에 열 수 있고, 6·27번은 첫 발판의 짧은 접촉 후 재도약할 수 있다. 25·31번은 실제 착지 제동으로 앞 장애물을 조기에 해제한다.
- 17번 충전으로 높은 받침에 올라, 17~19번을 가로지르는 y=240 컨베이어를 타고 20번 사슬로 이탈하는 숙련 경로가 있다. 추가 체크포인트나 해제 영구 저장 없이 실제 입력으로 통과한다. 일반 지상 경로도 유지한다.
- 23번은 판 체류 후 사슬에 매달리고, 높이를 조절해 이탈한 뒤 x=568/y=230 충전을 받아 x=616/y=200 벽을 넘는 연속 동작이다. 실제 공략 입력에서 충전 획득을 확인한다.
- 사슬은 A/D로 흔들림을 쌓으며 이탈 시 접선 방향 속도를 상속한다. 상승·하강·중간 점프·벽 오르기는 같은 입력을 사용한다.
- 압력판(14·23·35·36)과 감지 위치(11·12)의 바닥 선을 제거했다. 숨은 바닥은 주변과 같은 잔디·흙·식생으로 그리고, 긴 세로 화면에서도 지면 아래를 채운다. 접촉 범위·센서는 그리지 않는다. 24번의 균열·파편·충격음은 강한 착지로 실제 파손된 뒤 발생한다.

## 구조

- `course.gd`: 구간별 바닥 틈·고정 지형·동적 표면·기믹 배치. 구간별 실제 길이를 사용하며 카메라 잠금이나 방 전환이 없다.
- `world.gd`: 모든 충돌 지형을 한 번 구성하고 현재 카메라 범위만 그린다. 이전 해상도 맞춤·최대화·F11 복귀를 유지한다.
- `encounter.gd`: 40개 감지/판단과 대기→발동→활성→소진 상태. 물리 120Hz 시계로 위험 도형, 스위치, 이동 표면을 갱신한다. 사망 횟수나 난수로 규칙을 바꾸지 않는다.
- `surface.gd`: 실제 콜라이더를 가진 붕괴/이동/승강/벨트. 캐릭터에 표면 변위와 접촉 중 벨트 속도를 적용하고 이탈 속도를 추가 상속하지 않는다.
- `device.gd`: 실제 접촉으로 얻는 공중 점프 1회 충전, 다리/미끼 아이템, 점프대, 매달리고 오르내리는 사슬.
- `player.gd`: 기본 이동/가변 점프/코요테/버퍼, 충전 공중 점프, 벽 슬라이드·W 오르기·벽 점프, 사슬 오르내리기와 점프 이탈. 점프대는 -760px/s로 발사하며 버튼 해제로 잘리지 않는다.

사망·재시작은 모든 센서, 타이머, 발자국 예약, 표면 위치·충돌, 아이템, 미끼, 압력판, 가짜 연출, 사슬 소유와 임시 점프 충전을 함께 초기화한다. 이미 활성화한 체크포인트는 사망 시 유지한다. 일시정지 중 입력과 시계·표면·사슬은 멈춘다. 가짜 피격과 가짜 문은 실제 사망/클리어/입력 잠금을 호출하지 않는다.

## 기록 호환

같은 사용자 폴더와 기존 저장 형식을 사용한다. 누적 시작/사망/클리어와 소리 설정은 보존한다. 맵이 달라진 이전 최고 시간·무사망·비밀 기록은 `legacy`의 이전 코스 키(`meadow-v1`, `continuous-40-v1`)로 보관하고 새 코스의 해당 기록을 별도로 시작한다. 플레이 도중 위치는 현재 체크포인트에서만 복귀하며 프로그램 재실행 후 위치를 복원하는 기능은 기존처럼 제공하지 않는다.

## 검증

- `playthrough.gd`: 시작부터 실제 이동·점프·W 입력만으로 일반 경로를 통과한다. `--fast`는 상부 컨베이어·첫 발판·제동을 사용하는 숙련 경로이며 별도 입력 테이프를 저장한다. `--room=N`은 개발용 단일 재현이다.
- `replay.gd`: 각 테이프를 30fps로 재생해 매 물리 틱의 위치와 시간을 비교한다. `--pauses`는 실제 탑승 상태에서 수집한 이동 발판·사슬·승강기 세 지점에서 일시정지/재개한다.
- `gameplay_revision_tests.gd`: 기존 후퇴·대기 우회 실패, 실제 행동에 따른 조기 통로 개방, 약한/강한 착지, 사슬 입력과 속도 상속, 이전 최고 기록 보관을 검사한다.
- `wrong_routes.gd`: 40개 각각의 오답 입력이 실제 사망으로 이어지는지 검사한다. `course_tests.gd`는 전체 초기화·정지·재현을 검사한다.

전체 일반 공략 **148.975초 / 17,877틱**, 숙련 공략 **135.508초 / 16,261틱**, 모두 사망 0회·체크포인트 2개·비밀 별이다. 17~23 재주행은 동일 코스 일반 입력 27.24초, 숙련 입력 22.88초로 약 4.36초 짧다. 지상 정지 시간은 일반 21.68초, 숙련 10.62초이며 전부 강제 대기를 뜻하지는 않는다. 이는 작성한 입력의 재현 결과이고 초견 난이도나 인간 플레이어 평균 기록을 측정한 수치는 아니다.

Linux X11/Mesa의 렌더 캡처는 숨은 판 4곳, 파손 전후, 세로로 긴 화면의 지면, 초반 지형과 상부 길을 확인했다. 시각 점검용 초기 위치 지정은 전체 공략 결과에 포함하지 않는다. 테스트·Windows 설치 검증 결과는 `VALIDATION.md`에 기록한다.
