# 요소 공통 규칙 — 0.5.1

`scripts/elements.gd`가 요소 종류, 그룹, 재질, 접촉 규칙과 기본 머리 공간을 정의한다. 크기를 보고 위험물 종류를 추정하지 않는다. 설명문이나 범례는 게임 화면에 넣지 않는다.

| 그룹 | 구성 | 공통 표현과 접촉 |
|---|---|---|
| `terrain` | 지면, 흙 기둥, 숨은 바닥 | 잔디와 흙. 밟거나 부딪혀도 접촉 자체는 비살상 |
| `platforms` | 이동 발판, 승강기, 컨베이어 | 평평한 밝은 상단과 청록색 금속. 안전한 운반체; 벨트에는 방향 무늬 |
| `mechanisms` | 머리 스위치, 걸쇠 문 | 같은 안전 금속에 황동 접점/걸쇠. 접촉 자체는 비살상 |
| `traversal` | 점프대, 사슬 | 공통 금속과 황동 스프링/밝은 연결 고리. 실제 이동 기능 유지 |
| `pickups` | 공중 점프 충전, 열쇠 | 공통 마름모 형태. 충전은 민트색, 열쇠는 황동색 |
| `hazards` | 고체 압착 문 | 어두운 철과 주황빛 테두리. 실제 고체 접촉 시 사망 |
| `hazard_sources` | 40개 구간의 공격 발생기 | 구간별 도형 데이터로 칼날/이빨/낙하물/천장을 그린다. 별도 노드를 매 틱 생성하지 않음 |

칼날은 원, 지상 분출은 이빨, 낙하/압착물은 덩어리, 천장은 얇은 바 형태를 유지하며 같은 위험 재질을 쓴다. 비살상 준비 상태는 차가운 금속색, 활성 상태는 주황 테두리를 사용한다. 구간별 작동 원리나 숨은 감지 영역을 텍스트로 알려주지 않는다. 숨은 바닥은 주변 지면과 같은 공통 렌더러와 월드 좌표 무늬를 사용하고, 작동 전 균열이나 센서 선을 그리지 않는다.

## 판정

- 지형/표면 충돌층은 1, 플레이어는 2. 안전 문과 치명적인 문은 같은 크기여도 명시한 종류에 따라 다르게 처리한다.
- 치명적인 고체는 `move_and_slide()`의 실제 접촉으로 판정한다. 이전의 문 바깥 2px 확대 영역을 제거했다.
- 원형 칼날은 원과 캐릭터 피해 상자의 접촉으로 검사한다. 사각형 모서리에 보이지 않는 피해가 없다. 다른 공격은 표시된 사각형을 쓴다.
- 이동 발판의 운반, 착지, 점프대/충전/사슬 조작은 기존 공통 플레이어 물리를 사용한다.

## 공간과 난이도

지형/장치의 재질 통일과 난이도 조정은 별개다. 시각 정리 요청만으로 점프 조건이나 정답 동작을 완화하지 않는다. 0.5.0에서 넓힌 첫 함정과 스위치/낙하물 위치는 0.5.1에서 원복했다.

- 첫 사각형은 작동 전 보이지 않는다. 공중 진입 조건 뒤 시계가 0.025초를 넘으면 x=176/y=304, 폭168/높이18로 나타난다. 대기 하우징·0.18초 하강 동작을 제거했다. 첫 짧은 점프는 통과하고 긴 점프는 사망한다.
- 공통 낮은 천장은 원래 y=368/높이20에서 **y=352/높이20**으로 16px만 올렸다. 평지 y=416에서 귀까지37px를 포함해 7px를 남긴다. 테두리를 고려해도 최소6px를 남기는 기준이다. 짧게 눌렀다 떼는 점프도 부딪히므로 천장 밖에서 뛰거나 후퇴하는 기존 판단을 유지한다. 3·5번 옆으로 들어오는 칼날의 센서·속도·진행 방향·공격 시간은 바꾸지 않았다.
- 4·15·16 머리 스위치는 y=344/344/336, 12번 낙하물 대기 위치는 y=320, 16번 오답 낙하는 x=308, 36번 천장은 y=320/높이16으로 원복했다. 일반 천장의 간격 기준을 머리 접촉 스위치나 승강기 꼭대기에 강제하지 않는다.
- 후반 연속 공격에 별도 난이도 변경을 추가하지 않는다. 공통 색/종류와 센서 숨김, 기존 걸쇠 문 동작은 유지한다.

## 벽타기 범위

기본 벽 오르기·벽 점프·벽 미끄럼 감속은 사용할 수 없다. `course.gd`의 `climbable_solids`에 지정한 정적 지형만 `climbable_walls` 그룹에 넣는다. 현재는 14번 로컬 x=344/y=224의 기둥 한 개다. 방 전체, 모든 흙 벽, 이동 발판이나 문을 허용하지 않는다. 지정 벽에는 금속 손잡이를 그리며 안내문은 추가하지 않는다.

플레이어는 직전 실제 측면 충돌의 콜라이더와 법선을 확인해 세 기능을 함께 허용한다. 전용 벽에서 떠나면 일반 벽으로 권한이 넘어가지 않는다. 지상 점프·아이템 충전 공중 점프·사슬 동작은 유지한다. 특히 23번 높은 벽은 사슬과 실제 충전을 이용해 통과하며 자유 벽타기로 대체하지 않는다.

40개 구간의 길이와 두 체크포인트는 유지한다. 첫 점프 원복과 벽타기 제한으로 코스는 `continuous-40-v4`이며 v3 최고 기록은 보관한다. 누적 횟수와 설정은 유지한다. `elements_tests.gd`, `movement_scope_tests.gd`와 전체 두 경로·오답 40개를 검사한다. 새 요소는 공통 종류/렌더러/접촉 규칙을 재사용한다.
