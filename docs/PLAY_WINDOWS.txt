한 번만 더!

실행
  설치 후 시작 메뉴에서 One More Try!를 실행하세요.
  ZIP은 압축을 풀고 OneMoreTry.exe를 실행하세요.

조작
  A / D 또는 ← / → : 이동
  Space             : 점프
  W / S 또는 ↑ / ↓ : 오르내리기
  R                 : 다시하기
  ESC               : 일시정지
  M                 : 음소거
  F11               : 전체 화면

업데이트
  업데이트에서 정식·베타 채널을 선택하세요.
  새 버전을 자동으로 내려받습니다. 설치하고 종료를 누르면 설치합니다.
  v0.1.0 사용자는 설치 파일을 직접 실행해 주세요.

제거
  Windows 설정 > 앱 > One More Try!
