한 번만 더!

실행
  설치 후 시작 메뉴에서 One More Try!를 실행하세요.
  ZIP은 압축을 풀고 OneMoreTry.exe를 실행하세요.

조작
  A / D 또는 ← / → : 이동
  Space             : 점프
  W / S 또는 ↑ / ↓ : 오르내리기
  R                 : 다시하기
  ESC               : 일시정지
  M                 : 음소거
  F11               : 전체 화면

업데이트
  업데이트에서 정식·베타 채널과 자동 업데이트를 설정하세요.
  자동 업데이트가 켜져 있으면 실행할 때 확인하고 적용 후 다시 시작합니다.
  플레이 중에는 적용을 미룹니다. 꺼 두면 수동으로 확인할 수 있습니다.
  0.5.1 이하에서는 이번 버전을 한 번 설치해 주세요.

제거
  Windows 설정 > 앱 > One More Try!
