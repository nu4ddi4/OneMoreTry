# 40개 함정 연속 설계 — 배운 답을 다음 방이 배신한다

**상태: 구현 전 상세 설계. 40개 모두 아직 게임에 추가되지 않았다.** 좌표·타이밍·속도는 프로토타입용 초깃값이다. 실제 입력으로 통과시킨 뒤 확정한다. 기존 8개 초안을 확장했으며 가짜 골인 두 개는 39·40번으로 옮겼다.

## 구성과 진행 순서

기존 3600px 스테이지에 모두 밀어 넣지 않고 **5장 × 8개 = 40개**로 새 지형을 만든다. 각 장은 후보 길이 4096px다. 두 방을 한 묶음으로 공략하고 실제 체크포인트를 얻는다. 새 조작을 늘리지 않고 A/D, 점프 유지/해제, 공중 제동, 대기, 후퇴, 의도적 낙하를 조합한다.

첫 시도에서는 예상한 행동이 공격을 깨운다. 다음 시도에서는 기억으로 통과하지만 이어지는 다른 방이 그 해법을 역이용한다. 같은 방의 규칙은 사망 횟수에 따라 바꾸지 않는다. 40개는 서로 다른 만남이며, 모든 방에 별도의 새 기반 시스템을 하나씩 만들겠다는 뜻은 아니다. 공통 장치를 조합해 입력 순서와 판단을 다르게 만든다.

## 좌표·시간·조작의 공통 규약

- `R`은 해당 방의 시작 x다. 장 안의 방 1~8은 R=0, 512, 1024, …, 3584다. 전체 번호 n에서 장 번호는 1+(n-1)//8, R은 512×((n-1)%8)이다. 각 상세 문서의 R을 더하면 실제 장 좌표가 된다.
- `F`는 기본 발 높이 y=416이다. 위는 F-높이, 아래는 F+높이다. 현재 캐릭터 몸 충돌은 20×28px, 위험 접촉 판정은 18×26px다. 기본 머리 피격점은 발에서 27px 위다.
- 방 처음 96px와 마지막 48px는 연결/재정렬 영역으로 쓴다. 장치 종료점을 두어 이전 공격이 체크포인트나 다음 방 입구까지 쫓아오지 않게 한다. 39·40은 같은 체크포인트의 공통 시계를 쓰지만 실제 공격은 각 지형 안에 배치한다.
- `T`는 해당 센서나 명시한 사건의 첫 발동을 0으로 센 물리 프레임이다. 120Hz에서 12프레임=0.1초, 24=0.2초, 60=0.5초다. 시계는 음악·벽시계·렌더 프레임과 분리하며 일시정지 중 멈춘다.
- 최고 지상 속도 250px/s, 지상 가감속 2100px/s², 공중 가감속 1500px/s²를 유지한다. 최고 속도에서 입력을 놓은 뒤 추가 이동은 지상 약 15px, 공중 약 21px다. 숫자 앞에서 즉시 멈추는 해법을 쓰지 않는다.
- 알고 하는 핵심 조작의 성공 구간은 우선 8물리 프레임 이상, 약 67ms 이상을 목표로 한다. 입력 시작 시점과 유지 길이를 바꿔 실제 측정한다. 처음 보는 기습을 순발력으로 반드시 피할 수 있게 만들 필요는 없다.
- 기본안은 움직이는 플랫폼을 떠날 때 플랫폼 속도를 캐릭터의 점프 속도에 추가로 상속하지 않는 것이다. 지상 운반은 실제 이동으로 적용한다. 정책을 바꾸면 06·25~32의 거리와 타이밍을 모두 다시 측정한다.

## 현재 조작의 실측 범위

Godot 4.6.3, 물리 120Hz, 평지에서 오른쪽 최고 속도 250px/s를 유지하며 현재 플레이어 코드로 측정했다. 아래 수치는 실제 캐릭터의 발 위치 기준이다. 새 함정의 통과 검증 결과가 아니다.

측정 재현: `godot --headless --fixed-fps 120 --script tools/probe_jumps.gd -- --test`. 실제 사용자 기록은 읽거나 쓰지 않는다.

| 점프 키 유지 | 최고 높이 | 평지 착지까지 이동 | 비행 프레임 |
| --- | ---: | ---: | ---: |
| 1프레임 | 21.0px | 87.5px | 42 |
| 6프레임 | 35.4px | 108.3px | 52 |
| 12프레임 | 50.3px | 125.0px | 60 |
| 20프레임 | 66.3px | 143.8px | 69 |
| 45프레임 | 86.7px | 183.3px | 88 |

긴 점프와 짧은 점프의 차이를 함정의 해법으로 사용한다. 120Hz에서 1프레임은 약 8.33ms다. 공략을 안 뒤의 주요 입력 구간은 우선 **8프레임 이상**을 목표로 잡고 실제 장면에서 검증한다. 첫 도전의 기습을 순발력만으로 피할 수 있게 만들 필요는 없다.

이 표는 평지에서 같은 높이로 착지하는 측정이다. 코요테 타임을 사용하면 평지 도약 지점보다 더 앞으로 나간다. 높이가 다른 착지점과 이동 발판·컨베이어에도 그대로 적용할 수 없다. 스위치를 필수로 쓰게 하는 틈은 우선 256px로 잡되, 코요테·발끝 걸치기·플랫폼 추진까지 포함해 실제 우회를 검사한다.

## 체크포인트와 실제 게임 상태

- 장 시작과 두 방 묶음 뒤에 실제 체크포인트를 둔다. 장 안의 다음 스폰 후보는 x=1040, 2064, 3088이다. 현재처럼 깃발에서 24px 오른쪽에 부활시킨다면 깃발은 각각 1016, 2040, 3064에 둔다. 다음 센서 R+112까지 최소 96px를 확보한다.
- 장 출구 후보 x=4048에서 다음 장의 안전한 시작점으로 연결한다. 전체 클리어는 마지막 장 40번의 실제 문에서 한 번만 확정한다. 08·16·24·32는 실제 장 이동이며 가짜 성공이 아니다.
- 사망하면 현재 두 방 묶음의 타이머·위치·속도·문 걸쇠·미끼·압력판·왕복 회차·가짜 연출을 함께 초기화한다. 이미 획득한 실제 체크포인트는 유지한다. 39에서 시작한 40의 시계도 함께 초기화한다.
- 부활 자체와 다시 누르고 있는 D로 공격이 겹치지 않도록 안전 영역을 분리한다. 체크포인트를 켠 사실을 다음 시도에 거짓으로 돌리지 않는다.
- 미끼 별은 실제 영구 비밀 별과 분리한다. 가짜 피격과 가짜 골인은 실제 died, 실패 카운터, 자동 부활, finish_run, 최고 기록을 호출하지 않는다. R은 항상 실제 재시도이며 가짜 버튼으로 바꾸지 않는다.
- 게임 종료 뒤 장/체크포인트 진행을 복원하려면 별도 진행 저장이 필요하다. 현재 MVP는 기록만 영구 저장하고 진행 위치는 복원하지 않는다. 이 문서가 현재 실행 파일의 저장 동작을 바꿨다는 뜻은 아니다.

## 연출과 물리의 기준

플레이어가 보는 지역 이름은 초원·동굴·공장·하늘·성처럼 평범하게 쓴다. 이 문서의 장 제목·함정 이름·설계 의도는 개발자용이다. 게임 화면과 공개 소개에서는 전역 `plain-product-copy` 규칙에 따라 기능 문구만 남긴다.

팻말·해법 자막·유도 화살표는 추가하지 않는다. 공격은 발동한 뒤 실제 물체로 모습을 드러내고, 닿은 영역과 판정을 일치시킨다. 사망 원인의 물체·잔해·기계 위치를 자동 복귀 전까지 남겨 다음 시도에 공략하게 한다. 가짜 효과도 현재 음악/효과음 음소거 설정을 따른다.

전경 가림은 같은 월드 좌표에 고정한다. 같은 외형의 전경에 상황마다 임의의 충돌을 주지 않는다. 논리 화면은 960×540으로 유지해 모니터·창 크기로 먼저 보이는 위험이 달라지지 않게 한다. 장치의 소리 없이도 위치와 움직임으로 원인을 확인할 수 있게 한다.

## 구현 순서

1. 하드코딩한 월드를 장/방 리소스, 스폰·체크포인트·출구 데이터로 분리한다. 현재 지형 위에 40개 장치만 겹치지 않는다.
2. 공통 상태를 대기→발동→1차 공격→후속 공격→소진으로 만들고 물리 시간으로 전이한다. 입력·위치 이력으로 갈라지는 선택은 명시하고 숨은 난수는 쓰지 않는다.
3. 01~04의 수직 단면을 실제 입력으로 완성한 뒤 05~08을 붙여 첫 장 전체를 통과시킨다.
4. 횡이동/낙하 장치, 해제형·체류형 압력판, 머리 스위치, 예약 타일, 이동 발판·컨베이어·승강기를 순서대로 추가한다.
5. 09~32를 장 단위로 통과시킨 뒤 33~40의 조합을 붙인다. 37·39의 FakeImpact/FakeFinish는 실제 게임 상태와 분리한다.

## 각 방의 완료 조건

상세 카드마다 자연스러운 오답과 알려진 공략을 모두 재현한다. 최소 오답 2개, 공략 1개, 입력 시작/유지 시간의 성공 구간, 동일 입력 반복, 중간 일시정지, 사망 후 초기화, 코요테·모서리 우회, 다음 방까지의 연결을 검사한다. 플레이어 순간 이동만 사용한 시험으로 통과를 주장하지 않는다.

의도하지 않았지만 숙련으로 가능한 우회는 기록하고 인정할 수 있다. 반면 장치가 발동하지 않는 공통 입력 하나로 전 구간을 통과한다면 설계를 다시 본다. 조작 여유가 한두 프레임에만 몰리면 성공 구간을 넓히도록 속도·폭·지연을 수정한다.

검증 전에는 ‘새 함정 통과 가능’, ‘8프레임 여유 확보’를 확정 결과로 적지 않는다. 현재 확정된 실측은 위 평지 점프 표다. 연결된 전용 게임 설계 스킬은 없으며 이 문서와 40개 카드를 반복 사용하는 검토 기준으로 남긴다.
