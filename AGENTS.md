For player-facing wording, apply the user-level `plain-product-copy` skill (`~/.agents/skills/plain-product-copy/SKILL.md`) when available. Keep only necessary functional labels. Do not disclose hidden mechanics, design intent, hints, or the absence of hints. Do not add a replacement slogan when deleting explanatory text. Keep design details in developer documentation.

Work directly on main during the current 0.x development phase; do not require feature branches, beta integration, or pull requests. Use beta only when the user requests a separate preview. Follow docs/DEVELOPMENT.md. Whenever the version increases, publish Windows installer/portable releases automatically after checks: beta uses vX.Y.Z-beta prereleases and main uses vX.Y.Z stable releases. Never replace an already published version.
